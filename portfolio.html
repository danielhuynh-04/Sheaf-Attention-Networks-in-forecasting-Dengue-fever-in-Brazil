Leveraging Algebraic Topology on Graphs to Predict Dengue Fever Outbreaks in Brazil
PythonPyTorchPyTorch Geometric Sheaf Neural NetworksGraph Attention Networks SQLGeoJSONScikit-learn
📅 May 2025 – Mar 2026 👤 Student Principal Investigator 👥 3-member team 🏥 Validated with Hospital for Tropical Diseases physician
Overview
  • Led the full research lifecycle: authored the proposal (literature review, research gap, methodology, experimental design), managed team execution via Gantt chart and milestone tracking, and controlled a VND 5M university budget.
  • Core question: Can topological graph learning — specifically Sheaf Neural Networks — outperform classical Graph Neural Network architectures at predicting dengue outbreak weeks in a heterophilic epidemiological network?
  • Motivation: Classical Graph Neural Networks assume homophily (similar neighbors). Brazilian municipalities are heterophilic — urban/rural mix, climate zones, migration patterns — requiring direction-aware, asymmetric message passing.

5 Graph Neural Network Architectures Benchmarked
Simple Graph Neural Network
Baseline · Standard message passing
Standard message passing with equal neighbor aggregation. Assumes perfect homophily — every neighbor has identical influence. Serves as the weakest baseline.
Graph Convolutional Network
Spectral filtering · Symmetric normalized Laplacian
Spectral filtering via symmetric normalized Laplacian. Still assumes homophily — all neighbors contribute equally regardless of epidemic context.
Spatio-Temporal Graph Attention Network
Multi-Head Attention + Gated Recurrent Unit
Multi-head attention (α-weights) over spatial neighbors + Gated Recurrent Unit for temporal lag sequences. Hidden dimension=128, attention heads=(4,4).
Sheaf Neural Network
Algebraic Topology baseline · Sheaf Laplacian
Applies algebraic topology to graphs. Per-edge Restriction Maps F(v→e) replace standard Laplacian with Sheaf Laplacian. Handles heterophily — first model to break the homophily assumption.
🏆 Best Model
Sheaf-Connection Neural Network
Asymmetric Connection Maps · Layer Normalization · Residual
Extends Sheaf Neural Network with learnable asymmetric 2D rotation-based Connection Maps per edge. Captures direction-aware, non-symmetric disease transmission. Residual connection + Layer Normalization. Hidden dimension=64.
Sheaf-Connection Neural Network — Architecture Deep Dive
  • Each node v has a stalk — a local vector space split into S = hidden/2 pairs of 2D subspaces representing local disease state geometry.
  • For each directed edge (src→dst), an edge Multi-Layer Perceptron takes [h_src ‖ h_dst ‖ |h_src–h_dst|] and outputs S rotation angles θ per stalk.
  • Restriction map applied as 2D rotation matrix: mapped_src = R(θ) · h_src_stalk — mathematically faithful to Sheaf theory's connection structure, enabling direction-aware propagation.
  • Disagreement signal: diff = R(h_src) − h_dst, aggregated back to both endpoints to minimize structural inconsistency across the graph.
  • Stabilized with residual connection + Layer Normalization, followed by Exponential Linear Unit activation.
  • Temporal context from lag sequences mean-pooled through a lazy linear projection and fused into the node embedding before edge processing.
# Core sheaf restriction map computation (sheaf_connection.py) def _edge_rotations(self, h_src, h_dst): edge_feat = torch.cat([h_src, h_dst, torch.abs(h_src - h_dst)], dim=-1) # [E, 3H] theta = self.edge_mlp(edge_feat) # [E, S] rot[..., 0, 0] = torch.cos(theta) # 2×2 rotation matrix per stalk rot[..., 0, 1] = -torch.sin(theta) rot[..., 1, 0] = torch.sin(theta) rot[..., 1, 1] = torch.cos(theta) return rot # [E, S, 2, 2] # Restriction + disagreement aggregation mapped_src = torch.einsum("esab,esb->esa", rot, h_src_stalk) # apply rotation diff = mapped_src - h_dst_stalk # disagreement agg.index_add_(0, dst, -diff) # minimize disagreement
Training Setup & Leakage Controls
  • Optimizer: AdamW · Loss: HuberLoss (δ=1.2) for outlier-robust regression · Gradient clipping: max_norm=1.0
  • Early stopping: patience=30 epochs on validation HuberLoss; best checkpoint auto-saved as .pt file
  • Temporal split (leakage-free): Train 2010–2020 / Validation 2021–2022 / Test 2023–2024 — zero temporal leakage across boundaries
  • Validation safeguards: automated feature timestamp leakage scan, permutation importance testing, edge mask structural verification
  • Bias-correction at inference: Duan smearing estimator (primary, computed from training residuals e^r̄) + σ²-shift fallback; 99.9th-percentile headroom clamp on back-transformed real-space predictions

Project 02 — Capstone Thesis

Nationwide Dengue Forecasting
& Spatio-Temporal Dashboard

🎓 Capstone Thesis · HCMC Dept. of Science & Technology · Ho Chi Minh City Open University Library
End-to-End Spatio-Temporal Graph Attention Network for Dengue Forecasting Across All 5,564 Brazilian Municipalities
PythonPyTorch Geometric PlotlyMapbox GL JS Apache ParquetGeoJSON SQLJavaScriptHTML/CSS
📅 Jul 2025 – Sep 2025 🗺️ 5,564 municipalities · 16,382 graph edges 📚 Submitted to University Library
Overview
  • Scaled the research pipeline from a benchmarking study to a production-grade nationwide forecasting system covering every Brazilian municipality — the most comprehensive graph-based dengue study in the codebase.
  • End-to-end: raw open data → feature engineering → graph construction → model training → bias-corrected inference → interactive offline dashboard visible in any browser.
Nationwide Graph Design
  • Nodes: 5,564 Brazilian municipalities, each identified by a 7-digit IBGE geocode with weekly epidemiological state vectors.
  • Edges: 16,382 directed connections built via k-Nearest Neighbours (k=6) on WGS84 geographic coordinates — modeling geographic proximity as a proxy for disease transmission pathways.
  • Edge index encoded as PyTorch Geometric edge_index [2×E] tensors; automated symmetry, connectivity, and out-of-bounds sanity checks applied before every training run.
  • Multi-source node feature matrix: ECMWF ERA5 climate variables, IBGE census demographics, biome classification, Köppen zone, lagged incidence (lag-1–4 weeks); full preprocessing with log1p transform + StandardScaler.

  • Temporal Encoder: Gated Recurrent Unit processes the lag sequence → Multi-Head Attention over Gated Recurrent Unit hidden states → residual last-step output. Captures sequential temporal patterns of outbreak progression.
  • Spatial Encoder (Graph Attention Convolution): attention coefficient α_ij learned per edge — each municipality adaptively weights its neighbors based on their current epidemic state, not uniformly.
  • Loss: HuberLoss (δ=1.2) — robust against outlier municipalities with extreme incidence spikes. Optimizer: AdamW with weight decay.
Evaluation Suite
  • Regression: Mean Absolute Error · Root Mean Squared Error · Symmetric Mean Absolute Percentage Error · R² · Trimmed R² (1st–99th percentile) — clip extreme outlier municipalities before computing R² for a robustness check.
  • Classification projection: Area Under the Receiver Operating Characteristic Curve and Precision-Recall Area Under Curve derived from regression scores using the 90th-percentile of training incidence as the outbreak detection threshold.
  • Epoch-level logging: train loss, val loss, elapsed time, and best-val-so-far logged to CSV for convergence analysis and reproducibility.
Interactive Plotly / Mapbox Dashboard
  • Zero-server architecture: fully offline dashboard — Plotly Express + Mapbox GL JS + vanilla JavaScript/HTML. No Flask, no backend. Runs directly in browser.
  • Choropleth risk layer (Scattermapbox): municipality-level outbreak probability overlaid on Brazil map, color-coded by risk tier.
  • Error heatmap (Densitymapbox): spatial distribution of model forecast error — identifies regions the model struggles with.
  • Temporal trend charts: weekly predicted vs actual incidence by region; top-N highest-risk municipality ranking table.
  • Data exchange: model outputs serialized to Apache Parquet → converted to browser-readable JSON; GeoJSON/Shapefile processing for 5,564 municipal boundary polygon overlays.
